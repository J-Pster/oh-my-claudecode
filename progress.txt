## Patterns to remember

- New session-scoped state: ALWAYS use `resolveSessionStatePaths('name', sessionId, dir)` and read `paths.effectiveRead` / write `paths.effectiveWrite`. Branded types prevent silent swaps.
- New hooks reading session_id: use `resolveSessionId({ context: 'hook', hookPayload: input })` — payload wins.
- New CLI commands reading session_id: use `resolveSessionId({ context: 'cli' })` — env wins.
- Hot-path writes (per tool call): keep `withFileLockSync` scope minimal (read+update+write only); skip lock for best-effort external ops.
- Opt-in migration via OMC_MIGRATE_LEGACY_STATE=1 — never copy by default.
